# Agent 项目宪章与防漂移合同

**版本：** v1.0｜**状态：** FROZEN｜**修改权限：** 仅用户或经用户批准的 change request

## 1. 冻结的科学不变量

以下规则不可由 Agent 因“方便”“数据不足”“结果不显著”或“期刊目标”而静默修改。

### I1｜碱基组成是起点，密码子是功能桥梁
项目必须先描述碱基组成及其区室差异，再追踪其向同义密码子、氨基酸、低复杂度与蛋白层的传导。不得把密码子分析替代为起点，也不得停在全基因组 GC 热图。

### I2｜组成、突变与替换必须严格区分
- 参考基因组支持“组成”；
- 谱系比较支持“替换/固定过程”的有限推断；
- mutation accumulation、de novo 或高可信近中性低频变异才支持“突变偏倚”。

无直接证据时，输出必须使用“组成状态”“替换倾向”或“与某突变模型一致”，不得写成“该物种具有某突变率”。

### I3｜系统发育关系优先于样本数量
物种不是独立重复。生态、GC、密码子和氨基酸关联必须以独立谱系转换为信息单位。数千基因不能把十个物种变成数千个独立生态样本。

### I4｜每个标题级主张必须对应明确零模型
至少回答：“在保持什么不变时，这个信号是否仍存在？”
- 同义密码子：保持氨基酸序列与关键局部组成；
- 氨基酸残差：保持 orthogroup/同源位点、祖先状态、结构/功能约束；
- 重复/indel：保持长度、AT、局部序列与可比区室；
- 宿主/阶段关联：保持系统发育与数据质量。

### I5｜低复杂度必须保留版与屏蔽版并行
Asn/Lys 等低复杂度重复既可能是重要生物学，也可能淹没全蛋白组结论。任何核心结果必须说明：
1. 保留低复杂度时是否成立；
2. 屏蔽后是否成立；
3. 若只在低复杂度中成立，应转为“重复/可塑性”问题，不伪装成普遍蛋白适应。

### I6｜宿主组学不是核心依赖
宿主层默认只使用高可信生态元数据、寄生细胞类型、血红蛋白序列/组成、生命周期位置等。只有明确候选机制无法用寄生虫数据区分时，才可提出宿主代谢或组学升级；不得提前扩展为宿主多组学项目。

### I7｜物种数据采用不对称设计
- 全物种：基因组、CDS、蛋白、注释质量、orthology、系统发育；
- 少数深挖物种：阶段表达、蛋白、tRNA/翻译、必需性与扰动；
- 不强迫每个物种拥有相同数据模态，也不以缺失值填充制造“完整矩阵”。

### I8｜可解释模型承担主推断
描述统计、祖先状态/系统发育比较、线性或广义混合模型、位点/密码子模型及约束随机化承担主要结论。随机森林、深度模型、蛋白语言模型仅可用于候选排序、非线性探索或独立支持，不能用 feature importance 替代机制。

### I9｜Gate B 后只能有一条主轴
Gate B 前同时观察：
- T 轴：组成 → 编码残差 → 翻译/应激；
- P 轴：AT-rich 重复 → indel/CNV → 可塑性/逃逸。

Gate B 评审后必须选择 `TRANSLATION_PRIMARY`、`PLASTICITY_PRIMARY` 或 `STOP/DOWNGRADE`。另一轴只能作为扩展或补充，不能继续等权扩张。

### I10｜湿实验是条件性升级，不是固定工作包
只有一个候选在 Gate D 同时满足跨层残差、正交功能证据、生物学重要性和明确竞争机制时，才可提出最小决定性实验。实验应区分两种机制，不得只是重复一个已知表型。

### I11｜机制先于靶点
候选蛋白列表、结构预测、分子对接和 druggability 不能替代机制。只有机制节点成立后，才评估必需性、宿主选择性、结构可药性和进化逃逸。

### I12｜Nature Microbiology 是证据标准，不是结果承诺
若证据只支持资源图谱、现代比较基因组或中性传导，应主动调整故事与期刊。不得事后增加模态制造顶刊叙事。

## 2. 任务准入测试

任一任务必须同时满足：

1. 可映射到一个 Aim/WP/Milestone；
2. 说明它将更新哪个 Claim 或 Gate；
3. 有具体输入、输出和验收标准；
4. 说明结果为阳性、阴性和不确定时分别如何处理；
5. 不违反冻结不变量；
6. 所需成本与数据规模已知。

缺少任一项，任务状态为 `REJECTED_UNSCOPED`。

## 3. 变更控制

触发以下任一情况必须填写 `templates/T01_CHANGE_REQUEST.md` 并等待用户批准：

- 改变中心科学问题、目标期刊或主轴；
- 新增一个长期工作包或必做湿实验；
- 引入宿主组学、临床受控数据或大规模新测序；
- 改变 Gate 的 go/pivot/stop 标准；
- 替换发现层的核心物种设计而非单个质量淘汰；
- 单次预计下载 >100 GB、单项预计计算 >500 GPU 小时或需要付费数据库；
- 因现有结果不支持而拟改变主要零模型。

## 4. 不得静默执行的行为

- 猜测数据 accession、版本、许可或样本含义；
- 覆盖原始文件或在 raw 目录写派生结果；
- 修改下载文件名后不保存原始映射；
- 用插补补齐不存在的物种组学；
- 只报告显著结果而不更新负结果；
- 删除失败分支以“清理仓库”；
- 将外部文献结论当作本项目已经复现；
- 把“候选适应性残差”简称为“适应性”而没有功能证据；
- 使用作者私下提供、邮件索取或未公开数据。

## 5. 必须暂停并询问用户的条件

- 出现两个同样合理但会显著改变主故事的物种面板；
- 关键数据需登录、同意额外条款、人工申请或可能涉及受控人类数据；
- 需要付费或大规模算力；
- Gate 结果处于边界，且进一步工作成本明显；
- 合作方提供的新事实与本包冻结假设冲突；
- 自动获取失败且 `06_DATA_MANUAL_ACQUISITION.md` 未覆盖；
- 发现已发表研究基本完成了计划中的核心创新。

## 6. 主张语言合同

| 证据状态 | 允许语言 | 禁止语言 |
|---|---|---|
| 仅组成差异 | “富集”“组成偏移”“谱系相关” | “突变导致”“适应于宿主” |
| 系统发育与零模型后残差 | “候选功能残差”“与选择一致” | “受到正选择”“形成适应” |
| 外部翻译/蛋白证据 | “预测/关联翻译输出” | “直接调控耐药” |
| 自然或既有扰动支持 | “支持功能作用/条件依赖” | “充分证明因果” |
| 决定性扰动或等价自然实验 | “机制上导致/必要或足够” | 超出实验物种、阶段和条件的普遍化 |

## 7. 项目退出也必须可复现

若 stop 或降级，Agent 必须保留：
- 失败假设；
- 关键负结果；
- 已排除的替代解释；
- 可复用数据资源；
- 合理的期刊/资源输出路线。

项目不允许“无结果，所以换一个新故事并删除旧证据”。
