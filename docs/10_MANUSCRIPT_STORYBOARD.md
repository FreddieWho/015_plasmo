# Nature Microbiology 稿件故事板

## 1. 目标叙事

不是：
> 不同疟原虫有不同 GC、密码子和氨基酸偏好，我们发现了一批潜在靶点。

而是：
> 多次独立的基因组组成转换在疟原虫中产生了可量化的编码残差；这些残差预设了谱系特异的翻译应激与蛋白输出边界，并解释一个核心耐药或生命周期表型。

## 2. Figure 1｜组成演化与自然实验

**一句话主张：** Plasmodium 存在多个独立、区室化的组成演化状态，而非单一 AT 化轨迹。

**最低内容：**
- 高可信物种树；
- genome/CDS/四倍简并/非编码/细胞器组成；
- 关键独立转换；
- assembly/annotation 与 LCR 质量标记；
- 发现层/深挖层/外群设计。

**失败处理：** 独立转换不足则收缩类群，不进入跨生态普遍主张。

## 3. Figure 2｜碱基向密码子和氨基酸的定量传导

**一句话主张：** 碱基背景解释大部分全局差异，但少量编码特征超出组成和蛋白约束期望。

**最低内容：**
- 同义密码子反事实；
- 同源位点/祖先/结构控制的氨基酸残差；
- 方差解释或效应分解；
- LCR masked/unmasked；
- leave-one-clade-out；
- 负结果。

**失败处理：** 残差消失则翻译轴停止；评估可塑性轴或中性传导故事。

## 4. Figure 3｜跨谱系残差与功能趋同

**一句话主张：** 稳定残差在独立谱系中集中于同一类阶段/功能模块，而不是随机分布。

**最低内容：**
- 残差模块而非大排名表；
- 独立谱系方向一致性；
- 结构域/蛋白区室；
- 与生态/阶段的系统发育控制；
- 至少一个反例或边界物种。

**失败处理：** 只在 P. falciparum 成立则改为物种特异机制，不能继续写“Plasmodium-wide”。

## 5. Figure 4｜阶段翻译供需与蛋白输出

**一句话主张：** 序列残差预测阶段或应激中的 tRNA/翻译供需和 RNA—蛋白解耦。

**最低内容：**
- 深挖物种的表达加权需求；
- tRNA abundance/charging/modification 中至少一层；
- 蛋白或翻译输出；
- 药物/营养/阶段扰动中的方向一致证据；
- 第二物种或强自然对照。

**失败处理：** 只与 mRNA 表达相关而无翻译/蛋白证据，不得使用“翻译程序”。

## 6. Figure 5｜机制、适用边界与脆弱性

**一句话主张：** 一个组成衍生的翻译依赖连接到核心表型，并形成条件性、相对低逃逸的寄生虫脆弱性。

**最低内容：**
- 主机制图和两个竞争模型；
- 必需性/药物进化/自然变异；
- 结构或功能区室；
- 逃逸可达性与适用物种/阶段；
- 若触发新增实验，只放最决定性的结果。

**失败处理：** 若只能输出长靶点表，Figure 5 取消，稿件按资源/比较机制降级。

## 7. Extended Data

- 传统 RSCU/ENC/PR2/PCA；
- 完整物种与数据 QC；
- 替代注释和转录本规则；
- 全部 LCR/重复分析；
- 外群结果；
- 完整候选与负结果；
- 参数/零模型敏感性；
- 群体数据和结构补充。

## 8. 四种结局

| 场景 | 证据结构 | 投稿定位 |
|---|---|---|
| A 目标故事 | 跨谱系残差 + 翻译/扰动 + 核心表型 + 可证伪机制 | Nature Microbiology |
| B 资源与桥接 | 严密比较框架 + 独特资源 + 一项聚焦功能证据 | Nature Communications / PLoS Pathogens |
| C 中性传导 | 大多数差异由组成解释，适应性不足 | GBE / NAR Genomics and Bioinformatics / iScience 等 |
| D 可塑性转向 | repeat/indel/CNV 与逃逸形成强自然/功能证据 | 视闭环强度冲击 Nat Micro/Nat Commun |

## 9. 摘要的证据顺序

1. 领域问题：耐药/阶段适应与跨物种可迁移性；
2. 未解缺口：组成差异与功能差异混淆；
3. 方法原则：系统发育自然实验和跨层反事实；
4. 主要发现：独立转换、可解释比例、稳定残差；
5. 功能闭环：翻译/蛋白/扰动；
6. 意义：长期基因组演化限制短期应激响应空间。

不得在摘要中先写靶点数量或模型名称。
