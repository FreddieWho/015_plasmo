# 寄生虫专家协作与人工判断接口

## 1. 原则

Agent 负责可重复计算和证据管理；寄生虫专家用于校准生物学边界、物种/阶段意义和实验可行性。专家意见不是“无记录的最终答案”，而应转化为可引用来源、可检验假设或明确的领域约束。

## 2. M0 必须向专家确认

1. 候选物种中哪些参考品系最代表当前实验/领域共识；
2. 哪些基因组/注释已知存在严重亚端粒、抗原家族或组装问题；
3. 哪些物种/品系可稳定培养、转染或进行 ortholog replacement；
4. P. knowlesi、P. berghei/P. yoelii 中哪一个更符合合作方能力；
5. 哪些生命周期阶段最具临床/传播意义且可获得数据或材料；
6. P. vivax/P. malariae/P. ovale 的结论有哪些不能由参考基因组外推；
7. 宿主红细胞偏好和血红蛋白来源的已知例外；
8. 青蒿素耐药、休眠/恢复和营养应激中最认可的正/负对照；
9. 哪些 tRNA/aaRS/转运/蛋白稳态节点已有充分研究，避免重复；
10. 合作方可承受的最小验证类型及不可做事项。

## 3. Gate A 专家输入

- 组成转换是否与已知宿主/生命周期转换具有可解释对应；
- 某些异常是否很可能是注释或抗原家族问题；
- 是否存在生物学上更好的近缘匹配对照。

专家不应仅凭“看起来合理”将相关性升级为适应性。

## 4. Gate B 专家输入

- 翻译残差候选是否触及重要阶段/耐药机制；
- 可塑性信号是否落在已知抗原、端粒或耐药 CNV 区域；
- 选择哪一条主轴的生物学影响与验证可行性。

该节点必须形成书面 GO/PIVOT/STOP 记录。

## 5. Gate C/D 专家输入

- 候选机制是否真的新、是否有关键遗漏文献；
- 哪个实验能区分两种竞争机制，而不是只重复表型；
- 适合的物种、阶段、阳性/阴性对照；
- 结果在临床/传播场景中的真实边界；
- 是否值得维持 Nature Microbiology 目标。

## 6. 可选最小实验菜单（只用于讨论，不是承诺）

| 触发信号 | 最小验证类型 | 主要区分的问题 |
|---|---|---|
| 同一蛋白的同义密码子残差强 | 同义重编码 | DNA 编码层是否足以改变翻译/药物表型 |
| 跨物种保守蛋白差异集中 | ortholog replacement | 谱系序列是否具有可迁移功能 |
| 需求与特定 tRNA/aaRS 节点一致 | 条件扰动 | 供给端是否必要 |
| 营养预测改变药物存活 | 营养×药物交互 | 代谢环境是否调制耐药/恢复 |
| 起始与氨基酸负荷交互 | reporter | 停顿稳定与碰撞降解等机制 |
| 结论依赖跨物种普遍性 | 第二物种验证 | 排除 P. falciparum 特例 |

## 7. 会议记录要求

每次专家讨论必须记录：
- 日期、参与者；
- 被讨论的 Claim/Gate；
- 新事实、意见和证据来源；
- 分歧；
- 需要计算验证的事项；
- 是否触发 change request；
- 明确的下一决策点。
