# 路线图、证据门与交付物

## 1. 依赖结构

```text
M0/WP0 数据与问题审计
   ↓ Gate 0: 面板与可推断边界可行
M1/WP1 组成演化地图
   ↓ Gate A: 存在可靠、相对独立的组成转换
M2/WP2 跨层反事实分解
   ↓ Gate B: 选择翻译轴 / 可塑性轴 / 降级停止
M3/WP3 功能与扰动整合
   ↓ Gate C: 是否形成跨层机制候选
M4/WP4 机制聚焦与转化边界
   ↓ Gate D: 是否需要最小新增验证
M5 升级验证或公开数据收口与投稿
```

## 2. M0｜WP0：立项与数据审计

**目的：** 不做生物学结论，先确认“哪些问题可以被哪些数据回答”。

**必需输入：** 执行包、候选物种表、数据源清单、三篇起始工作（方案书、NAR、iScience）。

**交付物：**
- `M0_READINESS_AND_DATA_AUDIT.md`；
- 锁定或暂缓的 `species_panel.tsv`；
- 每个物种的 assembly/annotation 版本、质量等级与使用边界；
- 数据可访问性和磁盘/算力预算；
- 初始物种树可行性报告；
- 领域专家需要确认的问题清单。

**出口条件：**
- ≥8 个高质量 Plasmodium 候选可用于核心比较；
- 至少两个潜在独立组成对照；
- P. falciparum 和至少一个第二谱系具备深挖数据；
- 所有核心数据均可公开获取，不依赖作者请求。

**禁止提前：** 全量群体原始 reads、全量结构预测、宿主组学、大规模机器学习、靶点排名。

## 3. M1｜WP1：组成演化

**问题：** 不同谱系的组成差异真实存在吗？在哪里发生？是否代表多个转换？

**核心工作：**
- 基因组/区室/CDS/非编码/密码子位点/四倍简并位点的组成描述；
- 核、线粒体、顶质体分离；
- assembly/annotation/重复与 mappability 审计；
- 核心 orthogroup 物种树与组成祖先状态；
- 仅在有直接数据时讨论突变谱。

**交付物：**
- Figure 1 候选；
- 组成转换清单及独立性等级；
- 伪影排除报告；
- Gate A 评审材料。

### Gate A｜是否存在可用于自然实验的可靠组成转换？

**GO：** 至少两个相对独立对照，方向和区室模式可重复，且不由注释/低复杂度单独驱动。  
**PIVOT-SCOPE：** 只有一个类群可靠，则收缩为类群特异研究。  
**STOP/DOWNGRADE：** 数据质量决定主要模式，无法形成可信跨谱系比较。

## 4. M2｜WP2：碱基到密码子、氨基酸与蛋白架构的分解

**问题：** 观察到的编码差异有多少是机械传导，哪些是稳定残差？

**核心工作：**
- 同义密码子层：固定氨基酸及关键局部背景；
- 氨基酸层：固定 orthogroup/同源位点、祖先状态、结构/功能环境；
- LCR 保留/屏蔽、成熟蛋白/结构域分层；
- 组成型数据方法、系统发育协方差、leave-one-clade-out；
- 明确报告背景解释比例与负结果。

**交付物：**
- Figure 2 候选；
- 基因/位点/通路残差表；
- 稳健与不稳健候选的分层清单；
- 翻译轴与可塑性轴的证据对比；
- Gate B 评审材料。

### Gate B｜主轴选择

**TRANSLATION_PRIMARY：** 有少量稳定编码残差，跨独立谱系复现，并有明确翻译/阶段预测。  
**PLASTICITY_PRIMARY：** 编码残差弱或消失，但重复、indel/CNV 与抗原/耐药事件呈稳健耦合。  
**DOWNGRADE/STOP：** 两轴均缺乏超出背景的可信信号。

**硬规则：** Gate B 后项目状态必须写入 `active_axis`，不得继续长期双主线。

## 5. M3｜WP3：功能整合

### 若翻译轴为主

**问题：** 残差是否预测阶段特异翻译供需、RNA—蛋白偏离或药物/营养应激？

**可用证据：**
- Malaria Cell Atlas 与阶段转录组；
- iScience 的 mRNA/tRNA 与蛋白组；
- Nature Microbiology 的 tRNA 修饰、codon-biased translation、RSA/药物数据；
- P. falciparum/P. knowlesi/P. berghei 必需性；
- 体外药物进化与自然群体数据。

### 若可塑性轴为主

**问题：** 重复背景是否超出可检测性与 AT 期望，预测 indel/CNV、抗原变化或耐药逃逸？

**可用证据：**
- NAR mutation-accumulation 数据；
- MalariaGEN Pf8/Pv4 变异与 CNV；
- Luth 等体外进化 SNV/indel/CNV；
- 亚端粒与家族特异注释。

**交付物：**
- Figure 3–4 候选；
- 每个候选的跨层证据卡；
- 至少两类功能证据的一致性/冲突报告；
- Gate C 评审材料。

### Gate C｜是否形成机制候选？

**GO：** 至少一个候选模块同时满足：稳定残差、独立功能证据、核心生物学表型、明确替代解释。  
**PIVOT：** 信号只在单一物种成立，改为物种特异机制并调整主张。  
**STOP/DOWNGRADE：** 残差不能预测任何翻译/蛋白/扰动表型。

## 6. M4｜WP4：机制聚焦与转化边界

**目的：** 从候选集合收缩到 1 个主机制和 1–3 个节点，避免“候选清单论文”。

**工作：**
- 合并序列、阶段、翻译、必需性、药物进化与结构信息；
- 评估跨物种保守性与适用边界；
- 评估单碱基可达逃逸、自然变异容忍度和结构功能约束；
- 明确两个竞争机制及可区分预测；
- 判断公开数据是否已足够，或需一个最小新增实验。

**交付物：**
- Figure 5 候选；
- 主机制图；
- 候选证据总表；
- 新增验证的必要性论证；
- 目标期刊重新评估。

### Gate D｜是否触发湿实验升级？

**NO-NEW-EXPERIMENT：** 公开扰动/自然实验已能闭合主推断。  
**MINIMAL-EXPERIMENT：** 只允许一个能区分竞争机制的最小实验，如同义重编码、ortholog replacement、目标 tRNA/aaRS/转运扰动或营养×药物交互。  
**DOWNGRADE：** 只有大规模多物种实验才能维持主张，则先调整稿件层级，而不是把项目无限膨胀。

## 7. M5｜升级或收口

可能结果：

- **A｜目标故事：** 跨谱系残差预测翻译应激并连接耐药/阶段表型；Nature Microbiology；
- **B｜机制较弱但资源完整：** Nature Communications / PLoS Pathogens / iScience；
- **C｜中性传导：** 比较进化/基因组学期刊；
- **D｜可塑性转向：** 若自然变异/功能闭环足够，仍可保持高目标。

## 8. 子 Agent 任务包标准

每个子任务必须使用 `templates/T05_TASK_PACKET.md`，包含：
- 唯一 task_id；
- 对应 Aim/WP/Milestone/Gate；
- 明确输入文件及版本；
- 允许的方法范围；
- 必交输出；
- 验收标准；
- 不允许的外推；
- 失败/不确定的返回格式。

子 Agent 无权修改项目状态，只能提交证据；主 Agent 负责合并并更新 Gate。
