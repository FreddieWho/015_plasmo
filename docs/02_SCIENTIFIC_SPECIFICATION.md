# 科学规格书

## 1. 中心科学问题

> 疟原虫谱系间的基因组组成转换，哪些只是突变、历史和蛋白约束的被动后果，哪些被编码层放大为翻译应激程序或基因组可塑性，并进一步影响耐药、增殖和生命周期适应？

## 2. 目标主张（待证假设，不是预设结论）

**Lineage-specific genome composition shifts have been co-opted to encode distinct translational stress-response programmes across Plasmodium.**

中文：不同疟原虫谱系的基因组组成转换被选择利用，编码了不同的翻译应激响应程序。

该主张只有在 Gate C/D 通过后才可进入标题或摘要。M0–M2 阶段只能称为“工作假设”。

## 3. 概念定义

| 概念 | 项目定义 | 最低数据要求 |
|---|---|---|
| 碱基组成偏倚 | 基因组、区室或位点上的 A/T/G/C 比例差异 | 高质量序列 |
| 突变偏倚 | 新生突变类型的发生概率不对称 | mutation accumulation、de novo 或高可信近中性低频变异 |
| 替换/固定偏倚 | 某类变化更常沿谱系固定 | 多物种/群体序列和适当进化模型 |
| 同义密码子偏好 | 氨基酸不变时的非随机密码子使用 | CDS、局部组成、表达/tRNA 等协变量 |
| 氨基酸偏好 | 蛋白或蛋白组氨基酸组成的系统变化 | orthology、结构/功能与低复杂度控制 |
| 候选适应性残差 | 相对“组成 + 系统发育 + 蛋白约束”期望的稳定偏离 | 明确反事实与敏感性分析 |
| 翻译稳健性 | 在阶段、营养或药物变化中维持目标蛋白输出的能力 | tRNA/翻译/蛋白或扰动证据 |
| 进化逃逸责任 | 候选靶点通过可达突变保留功能而逃避干预的可能性 | 密码子可达性、变异、结构与必需性 |

## 4. 科学假设与可证伪预测

### H1｜多状态组成演化
**假设：** Plasmodium 并非沿单一 AT 化轨迹演化，而是存在多个谱系与区室特异的组成状态。

**支持预测：**
- 全基因组、四倍简并位点、非编码区和局部上下文显示可辨识但不完全同构的谱系转换；
- 至少两个相对独立的近缘/生态对照支持不同方向的变化；
- 信号不由某个低质量组装或少数亚端粒家族独占。

**否证/收缩：**
- 转换主要由注释差异或单一类群分裂解释；
- 独立转换不足以支持跨谱系生态推断。

### H2｜跨层机械传导但非完全解释
**假设：** 碱基背景解释大部分密码子差异和部分氨基酸差异，但存在少数稳定功能残差。

**支持预测：**
- 固定氨基酸后仍有部分同义选择超出局部 GC/二核苷酸期望；
- 固定 orthogroup、同源位点、祖先状态和结构区室后，少量基因/通路在独立谱系中出现一致偏移；
- 结果在低复杂度屏蔽、替代注释和 leave-one-clade-out 后保持。

**否证/转向：**
- 所有显著模式被组成背景、低复杂度或注释解释；
- 则拒绝翻译适应主轴，评估可塑性轴或降级为中性传导资源。

### H3｜序列编码的翻译应激程序
**假设：** 稳定残差集中于特定生命周期与应激模块，并与 tRNA/翻译供需和 RNA—蛋白输出相匹配。

**支持预测：**
- 快速增殖、侵袭、性发育、孢子体成熟或应激恢复模块出现表达加权的异常密码子/氨基酸需求；
- 残差能预测至少一种独立信号：tRNA abundance/charging/modification、Ribo/polysome、mRNA 稳定性、RNA—蛋白偏离或药物/营养扰动；
- 不同谱系可依赖不同限制性氨基酸或密码子组，而非机械复制 P. falciparum 的 Ile 结论。

**否证：**
- 残差只随表达量或蛋白长度变化，不能预测任何翻译/蛋白/扰动证据。

### H4｜条件性可转化脆弱性
**假设：** 组成演化造成的翻译依赖在特定阶段或耐药背景中形成不可替代、可区分且较难逃逸的脆弱性。

**支持预测：**
- 候选处于高阶段需求、供给受限、遗传必需、寄生虫特异/高度分化与低逃逸交集；
- 候选对药物、营养或翻译节点扰动有方向一致证据；
- 候选价值不是由一般高表达或一般必需性单独驱动。

**否证：**
- 所有候选只是已知广谱必需蛋白，组成分析没有提供新增机制或适用边界。

### H5｜基因组可塑性备选轴
**假设：** 若翻译残差弱，AT-rich 重复仍可能通过 indel/CNV、抗原家族和耐药基因剂量产生适应价值。

**支持预测：**
- 重复/低复杂度背景与自然 indel、CNV 断点、抗原变异或药物进化事件耦合；
- 关联在控制长度、AT、mappability 与基因组区室后仍存在。

**否证：**
- 结构信号同样由组装、比对和可检测性偏差解释。

## 5. 分析单元

1. **核心单拷贝 orthogroups**：承担物种树、祖先状态和主要跨物种推断；
2. **保守多拷贝家族**：研究功能创新，但与核心背景分开；
3. **谱系特异/输出/抗原家族**：仅用于宿主界面与可塑性轴；
4. **低复杂度保留版与屏蔽版**：双轨报告；
5. **结构域、信号肽、跨膜区、无序区、成熟蛋白**：防止蛋白物性混杂；
6. **核、线粒体、顶质体**：分别分析；
7. **物种/谱系转换**：生态关联的独立统计单位；
8. **基因/位点**：物种内机制与残差定位单位，但不是物种层变量的独立重复。

## 6. 物种设计

### 发现层
约 10–15 个 Plasmodium 代表物种，覆盖 Laverania、vivax/knowlesi 类群、啮齿类、人疟其他分支及必要的鸟类/灵长类对照。最终面板由 M0 数据质量审计锁定。

### 深挖层
优先 P. falciparum、P. knowlesi、P. berghei/P. yoelii，再根据可用数据选择一个组成差异显著的人疟物种。仅这些物种进入阶段、翻译、必需性与扰动整合。

### 外群层
Babesia、Theileria、Toxoplasma 等顶复门物种，用于界定 Plasmodium 特异性和红细胞生态趋同；外群不得与 Plasmodium 直接混入单一无分层回归。

## 7. 主张梯子

| 级别 | 可支持主张 | 最低证据 | 初始状态 |
|---|---|---|---|
| C0 描述 | 某物种/区室存在组成差异 | QC 后序列统计 | 可进行 |
| C1 进化 | 存在可重复谱系转换 | 物种树、祖先重建、独立对照 | 未通过 Gate A |
| C2 残差 | 差异超出组成/系统发育/蛋白约束 | 反事实、敏感性、效应量 | 未通过 Gate B |
| C3 功能 | 残差预测翻译/蛋白/阶段表型 | ≥2 类正交功能证据 | 未通过 Gate C |
| C4 机制/适应 | 序列特征参与或导致表型 | 决定性扰动或等价自然实验 | 条件性 |
| C5 转化 | 形成可干预且低逃逸脆弱性 | 机制 + 必需性 + 选择性 + 逃逸评估 | 条件性 |

## 8. Nature Microbiology 最低充分证据

1. 一个非平凡且可推广的寄生虫生物学原则；
2. 至少两个相对独立谱系，或一个强跨物种/自然对照；
3. 系统发育、低复杂度、注释和蛋白约束的严密反事实；
4. 至少两类正交功能证据；
5. 与耐药、休眠、增殖、侵袭、性发育或传播至少一个核心关切相连；
6. 一个可证伪机制和能区分竞争机制的验证/强自然实验；
7. 结论不依赖“物种更多”“图更多”或“模型更复杂”。

## 9. 负结果的科学价值与期刊路线

- 若大多数蛋白层差异可由 AT/GC 机械解释：形成中性传导与过度适应解释校正；
- 若翻译残差弱但重复/CNV 强：转入可塑性轴；
- 若两者均弱：完成高质量数据资源与方法基线，停止顶刊机制叙事；
- 不允许为保持目标期刊而事后选择性定义新残差。
